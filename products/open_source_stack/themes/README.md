# Themes — Corporate Design

Place Tailwind config and CSS variables here so Evidence pages use a consistent design system.

- **Brand colours:** e.g. `--color-primary: #003366`, `--color-brand-header`, `--color-surface`.
- **Tailwind:** Extend theme in `tailwind.config.js` with these variables; then use `fill-primary`, `text-brand-header`, `bg-surface` in generated pages.

Evidence can be configured to use a custom theme; point the app at this folder for shared tokens.
