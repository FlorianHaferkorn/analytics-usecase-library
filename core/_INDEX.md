# core — Golden Thread (_INDEX)

> `core/` ist die tool-agnostische Logikschicht von ALUCA: KPI-Katalog, Action Codes, Use Cases,
> Semantik- und Seitenvorlagen, Datenverträge, Marke. Hier steht die **Bedeutung**; `products/`
> setzt sie je Tool um, `tooling/` erzeugt und prüft. Use Cases und Reports referenzieren diese
> Definitionen, sie definieren sie nicht neu. Jeder Unterbereich hat eine `README.md` als
> Einstieg; dieser Index routet dorthin und hält das Register der übrigen Docs, damit das
> Drift-Gate (`../scripts/check_index.py`) keinen verwaisten Text übersieht.

| Feld | Wert |
|---|---|
| Stand | 2026-11-12 |
| Rolle | L0-Navigation für `core/`; Register aller `.md` außer `README.md` |
| Eigener Index | `strategy_operating_model/_INDEX.md` (Zielbild, Operating Model) regiert seinen Teilbaum selbst |
| Schema-Autorität | `../tooling/generator/schemas/` — `core/` hält Inhalte, keine Schemas |
| Spiegel | `templates/page_templates/tokens/` und `templates/page_templates/visual_library/` spiegelt Freelancing (Meridian) per PIN; dort nur mit Spiegel-Nachzug ändern |
