# Neutral artifact lifecycle fixture

This fixture demonstrates the customer-independent Project Package lifecycle contract.
Names, roles, paths and evidence references are synthetic. The fixture is not a record of
an actual customer approval or distribution.

It deliberately separates:

- an authored Markdown source from its generated DOCX projection;
- approval to share from the customer's pending decision;
- an internal draft from a customer-facing artifact;
- the current artifact state from the immutable publication event and file hash.
