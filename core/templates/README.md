# Core Templates

## Purpose

Reusable, governed templates for framework artifacts.

## Template groups

- `action_codes/` - action code and decision spine templates
- `data_contract_templates/` - fact and dimension contract templates
- `kpi_catalog_templates/` - KPI catalog structure templates
- `measure_templates/` - measure documentation templates
- `page_templates/` - 3-30-300 page system and governance mappings
- `silver_to_gold/` - mapping template from Silver contracts to Gold outputs

## Usage

Use templates as starting points only. Final definitions belong in:

- `core/action_codes/`
- `core/data_contracts/`
- `core/kpi_catalog/`
- `core/usecases/`
- `core/semantic_models/`
