# Insights Page Template

Purpose:
- Provide a pattern to explore root causes and insights after the overview page in the ActionReady Analytics Framework.

Structure:
- Diagnostic sections: variance decomposition, root causes, correlations.
- Guided narratives: key insights with short text + supporting visuals.
- Actions & hypotheses: suggested actions tied to insights; mark hypotheses to test.

Design Rules:
- Focus on “so what” with limited, high-signal visuals.
- Use consistent KPI/action code references; avoid duplicate measures.
- Keep navigation clear: back to overview, forward to explorer/drill.
