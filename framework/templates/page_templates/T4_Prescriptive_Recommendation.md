# Prescriptive / Recommendation Template (T4)

## Purpose
Recommendation-oriented pages for predictive/prescriptive UCs. Focus on impact simulation, recommended actions, drivers, and risk scoring.

## Visual Structure (Slots)

### 3-Second Layer
- Slot A – Recommendation Summary KPI
- Slot B – Impact Estimate
- Slot C – Priority Score

### 30-Second Layer
- Slot D – Feature Importance / Driver Contribution
- Slot E – Correlation or Risk Score Distribution

### 300-Second Layer
- Slot F – Recommended Actions Table (mandatory)
- Slot G – Detail Drilldown (optional)

## Visual Standards
Allowed: KPI Cards, Horizontal Bar, Histogram, Boxplot, Scatter (T4 only), Table  
Forbidden: Funnel (except explicit Funnel-UC), Tree, Gauge, Maps.

## Slicers
- Segment
- Time
- Entity selector
