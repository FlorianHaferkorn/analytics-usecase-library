# Overview Page Template (3-30-300)

Purpose:
- Provide a standard overview page layout for the ActionReady Analytics Framework with fast “what / so what / now what”.

Structure:
- Hero KPIs: 1–3 primary KPIs with Δ/% vs Plan/LY, status chips, and action code hints.
- Drivers: Top drivers (price/volume/mix, OTIF, churn, etc.) with small multiples.
- Actions: Recommended actions (linked to action codes) surfaced near the KPI.
- Filters: Minimal, pre-set to key segments/time; no filter sprawl.

Design Rules:
- 3-second headline, 30-second storyline, 300-second drill path.
- Limit visuals; prefer comparisons and trendlines with clear labels.
- Consistent symbols (Δ, %, currency) and colors; avoid clutter.
