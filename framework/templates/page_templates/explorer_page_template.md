# Explorer Page Template

Purpose:
- Provide a flexible drill/exploration page for deeper analysis while staying aligned to the ActionReady Analytics Framework.

Structure:
- Slicers for key segments/time; controlled set to avoid overload.
- Detail views: tables or pivots with sortable columns and KPI highlights.
- Drill paths: from overview/insights into dimensions (org, product, channel, time).

Design Rules:
- Keep filters intentional; avoid “filter sprawl”.
- Highlight action-relevant KPIs; keep calculations consistent with catalogs.
- Provide reset/back navigation to maintain user context.
