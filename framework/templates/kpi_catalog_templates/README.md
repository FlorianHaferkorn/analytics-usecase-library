# KPI Catalog Templates

## Purpose

This folder contains the **canonical schema** for KPI Catalogs
used across all business domains.

It defines **how KPIs must be documented**, not which KPIs exist.

---

## Core Rule

> Each business domain has exactly **one KPI Catalog**.

That catalog is the **Single Source of Truth** for:
- KPI definitions
- ownership
- impact dimension
- actionability
- references to measures and data contracts

---

## Usage Rules

- KPI definitions live in domain KPI Catalogs
- This schema is used when:
  - creating a new domain catalog
  - validating existing catalogs
- Do not copy or fork schemas
