# Domain KPI Catalog

Purpose:
- Index the domain KPI catalogs used by the ActionReady Analytics Framework.

Where to find KPIs:
- Domain catalogs (migrated from legacy `_includes/kpi_catalog`).
- Measure dictionaries per domain under `semantic_models/domains/`.

Usage:
- Use KPI IDs from the domain catalogs as the only valid identifiers.
- Cross-check use cases and semantic models against these IDs before build.
- If a KPI is missing, propose it in the appropriate domain catalog; avoid duplicates.
