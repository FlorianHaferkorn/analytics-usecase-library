# Glossary (archived)

This folder is a **historical snapshot** of the former `core/glossary/` content. It is **not** a source of truth.

- **Why archived:** The glossary was not actively maintained. Presenting it as canonical would create a shadow standard and drift.
- **Current grounding:** Terminology is defined by governed SSOT only:
  - KPI definitions: `core/kpi_catalog/KPI_Catalog.md`
  - Use-case configuration: `core/usecases/**/UseCase_Bracket.yaml`
  - Action logic: `core/action_codes/**/*.yaml`
  - Semantic metadata: measure/table/column descriptions in semantic models and data contracts.
- **Future replacement:** Any new "glossary" must be **generated** from the KPI catalog and other SSOT artifacts, not maintained by hand.

Files in this folder: `glossary.md` (snapshot), `glossary_README_original.md` (original core README).
