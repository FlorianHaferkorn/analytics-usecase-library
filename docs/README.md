# Documentation

This folder contains all documentation related to the **Analytics Use Case Library**.  
It defines how use cases are structured, reviewed, and maintained.

## Structure
| File | Purpose |
|------|----------|
| **Instructions.md** | Rules for creating and maintaining use cases (format, naming, workflow). |
| **Methodology.md** | Explains the rationale and principles (3–30–300, semantic modeling, naming conventions). |
| **Changelog.md** | Tracks all approved changes, additions, and version updates. |

## Guidelines
- Keep documents concise and standardized.
- Use Markdown only (no embedded Office files or PDFs).
- Update `Changelog.md` whenever a new version or document is added.
- Last update date must be maintained in each file.
