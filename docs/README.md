# Documentation

This folder contains all documentation related to the **Analytics Use Case Library**.  
It defines how use cases are structured, reviewed, and maintained in alignment with the company-wide **Reporting Framework**.

---

## Structure
| File | Purpose |
|------|----------|
| **Reporting_Strategy.md** | Describes the overall reporting framework, including reporting levels, analytics maturity, and governance layers. |
| **Methodology.md** | Explains the methodological foundation (3–30–300 principle, semantic modeling, naming standards). |
| **Instructions.md** | Defines authoring, formatting, and review workflow for use cases. |
| **Changelog.md** | Records all approved changes, additions, and version updates. |

---

## Guidelines
- Keep documents concise, standardized, and Markdown-only (no embedded Office files or PDFs).  
- Follow naming conventions and structure from `Instructions.md`.  
- Update `Changelog.md` whenever a new version or document is created or modified.  
- Ensure each document has a `Last updated` section with a current date.  
- Use relative links between documents for easy navigation.
