# AI Readiness

Purpose:
- Ensure data, models, and governance enable reliable Copilot/Agent scenarios in the ActionReady Analytics Framework.

Guidelines:
- Grounding: KPIs and action codes must use stable IDs, linked to catalogs and semantic models.
- Quality: Define RI/QA rules per contract; monitor drifts and anomalies.
- Security & compliance: Enforce access, PII handling, and audit trails before enabling generative features.
- Guardrails: Maintain anti-patterns/synonyms lists to reduce hallucinations; prefer retrieval over generation for facts.

Actions:
- Validate data contracts and semantic models against AI consumption needs.
- Keep dictionaries (glossary, KPI catalogs) current and machine-readable.
- Document prompt patterns and escalation paths for AI outputs.
