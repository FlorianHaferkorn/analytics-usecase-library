# Data Governance

Purpose:

- Define how data is owned, secured, and validated across the ActionReady Analytics Framework.

Principles:

- Ownership: each domain has accountable owner/steward; contracts list contacts and approvals.
- Quality: RI/QA rules per contract; monitor completeness, timeliness, and drift.
- Security & access: least privilege, PII handling, audit trails; align with compliance policies.
- Lineage & catalog: KPIs and measures traceable to contracts and semantic models.

Practices:

- Embed QA asserts in data contracts; enforce in pipelines.
- Maintain catalogs (KPIs, glossary, action codes) as single sources of truth.
- Periodic governance reviews for changes to schemas, KPIs, or access.
